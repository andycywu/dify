# REST to SOAP Proxy Server

## 安裝依賴

```bash
npm install
```

## 啟動本地伺服器

```bash
npm start
```

## Docker 打包與執行

```bash
docker build -t rest-to-soap-proxy .
docker run -p 3000:3000 rest-to-soap-proxy
```

## API 範例

POST /createIssue
- Body: 需符合 WSDL 服務的 CreateIssue 方法參數格式

curl -X POST http://localhost:5001/GetIssueInfo \
  -H "Content-Type: application/json" \
  -d '{"issueID":1484510,"includeFields":true,"includeAttachments":false,"includeRecords":false}'

你可以根據需求擴充更多 REST 端點，對應不同的 SOAP 方法。
