🤖 Wiki.js AI 聊天機器人

具有 Dify 後端的智能知識助手

⚠️ 注意： 這是一個聊天機器人的演示界面。要獲得完整的 AI 功能，需要配置 Dify API Key。
AI 助手 線上
🤖 您好！我是 Wiki.js 的 AI 助手。我可以幫您：
• 回答關於 Wiki 內容的問題
• 搜索相關文檔
• 提供使用指導
• 解釋技術概念

集成狀態

✅ 1. Wiki.js 服務

Wiki.js 運行在端口 3002，狀態正常

✅ 2. Dify API 服務

Dify API 運行在端口 5001，狀態正常

⏳ 3. API Key 配置

需要配置有效的 Dify API Key 才能使用完整的 AI 功能

# 在 .env 文件中設置： DIFY_API_KEY=your-actual-api-key-here

⏳ 4. 聊天機器人集成

要在 Wiki.js 中顯示聊天機器人，需要添加自定義腳本：

// 在 Wiki.js 管理面板中： // 設置 → 主題 → 代碼注入 → 頁腳代碼 <script src="/chatbot-widget.js"></script>

🔗 集成完成後，聊天機器人將出現在所有 Wiki 頁面的右下角

訪問地址：

Wiki.js: http://localhost:3002

Dify Web: http://localhost:80
