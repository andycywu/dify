# Web 管理界面使用指南

## 🎉 已完成的功能

我們已經成功開發了一個功能完整的 **Web 管理界面**，用於管理 Wiki.js 批量導入和 SMB 同步功能。

## 🌐 訪問 Web 界面

打開瀏覽器訪問：

```
http://localhost:5050/
```

## 📋 主要功能模塊

### 1. 儀表板 (Dashboard)

**功能**:
- 📊 實時統計數據
  - 總同步文件數
  - 活躍群組數
  - 待處理文件
  - 失敗數量
- 📈 群組同步狀態一覽
- 🕐 最近同步活動記錄
- 🔄 每 30 秒自動刷新

**使用方式**:
1. 點擊側邊欄的「儀表板」
2. 查看統計卡片了解系統整體狀況
3. 查看群組狀態列表了解各組詳情

### 2. SMB 配置管理 (SMB Config)

**功能**:
- ➕ 新增 SMB 配置
- ✏️ 編輯現有配置
- 🗑️ 刪除配置
- 🔌 測試 SMB 連接
- 🔄 觸發單次同步

**使用方式**:

**新增配置**:
1. 點擊右上角「新增配置」按鈕
2. 填寫表單：
   - **群組名稱**: 從下拉列表選擇 (EE, ME_LCM, PWR, SW, PJM, etc.)
   - **SMB 路徑**: 容器內的 SMB 掛載點 (如 `/app/smb/EE`)
   - **Wiki.js 目標路徑**: Wiki.js 中的目標目錄 (如 `/smb/EE`)
   - **掃描間隔**: 自動同步的間隔時間（秒），默認 300
   - **啟用自動同步**: 勾選以啟用定時自動同步
3. 點擊「保存」

**測試連接**:
- 點擊配置卡片上的「測試」按鈕
- 系統會嘗試掃描 SMB 目錄
- 顯示找到的文件數量或錯誤信息

**觸發同步**:
- 點擊配置卡片上的「同步」按鈕
- 執行單次同步操作
- 完成後顯示同步結果

### 3. 同步監控 (Sync Monitor)

**功能**:
- 📋 查看所有同步任務列表
- 📊 查看同步統計數據
- 🔄 手動刷新狀態
- 📖 查看同步歷史

**使用方式**:
1. 點擊側邊欄的「同步監控」
2. 查看各群組的同步任務狀態
3. 點擊「刷新」更新最新狀態
4. 點擊任務的「同步」執行即時同步
5. 點擊「詳情」查看詳細信息

### 4. 批量導入 (Batch Import)

**功能**:
- 🔍 掃描目錄預覽
- 📤 批量目錄導入
- 📊 實時進度顯示
- 📝 詳細導入結果

**使用方式**:

**步驟 1: 掃描目錄**
1. 輸入源目錄路徑 (如 `/app/smb/EE`)
2. 輸入 Wiki.js 目標路徑 (如 `/imported/EE`)
3. 選擇是否保留目錄結構
4. 點擊「掃描目錄」
5. 查看掃描結果：
   - 找到的文件列表
   - 文件大小和類型
   - 文件總數

**步驟 2: 開始導入**
1. 確認掃描結果
2. 點擊「開始導入」按鈕
3. 查看實時進度條
4. 導入完成後查看詳細結果：
   - 成功/失敗數量
   - 每個文件的狀態
   - Wiki.js 頁面 URL 鏈接

**選項說明**:
- **保留目錄結構**: 
  - ✅ 勾選: 保持原始文件夾層級
  - ❌ 不勾選: 所有文件導入到同一層級（扁平化）

### 5. 日誌查看 (Logs)

**功能**:
- 📜 實時日誌顯示
- 🎨 彩色日誌級別
- 🔄 手動刷新
- 🗑️ 清空日誌

**使用方式**:
1. 點擊側邊欄的「日誌查看」
2. 查看系統運行日誌
3. 日誌級別：
   - **INFO**: 一般信息（藍色）
   - **SUCCESS**: 成功操作（綠色）
   - **WARNING**: 警告信息（橙色）
   - **ERROR**: 錯誤信息（紅色）
4. 點擊「刷新」更新日誌
5. 點擊「清空」清除顯示

### 6. 系統設置 (Settings)

**功能**:
- ⚙️ 同步設置
- 📧 通知設置
- 🔔 Email 通知配置

**使用方式**:

**同步設置**:
1. **默認掃描間隔**: 設置 SMB 目錄掃描的默認間隔時間（秒）
2. **最大並發任務數**: 控制同時運行的同步任務數量
3. **啟用自動同步**: 全局開關，控制是否自動執行同步

**通知設置**:
1. **啟用 Email 通知**: 勾選以啟用郵件通知
2. **通知 Email**: 輸入接收通知的郵箱地址
3. 點擊「保存設置」

## 📱 快速操作流程

### 場景 1: 首次配置 SMB 同步

```
1. 訪問 http://localhost:5050/
2. 點擊「SMB 配置」→「新增配置」
3. 填寫表單:
   - 群組: EE
   - SMB 路徑: /app/smb/EE
   - Wiki.js 目標: /smb/EE
   - 掃描間隔: 300
   - 勾選「啟用自動同步」
4. 點擊「保存」
5. 點擊「測試」驗證連接
6. 點擊「同步」執行首次同步
```

### 場景 2: 批量導入文檔目錄

```
1. 點擊「批量導入」
2. 輸入源路徑: /app/smb/EE/project-docs
3. 輸入目標路徑: /projects/EE/docs
4. 勾選「保留目錄結構」
5. 點擊「掃描目錄」→ 查看預覽
6. 點擊「開始導入」
7. 等待進度條完成
8. 查看結果並點擊 Wiki URL 驗證
```

### 場景 3: 監控同步狀態

```
1. 點擊「儀表板」查看整體狀況
2. 查看統計卡片:
   - 總文件數
   - 活躍群組數
   - 待處理/失敗數
3. 查看群組狀態列表
4. 如需詳情，切換到「同步監控」
5. 查看各群組的詳細同步狀態
```

## 🔧 技術架構

- **HTML5** + **CSS3**

- **Vanilla JavaScript**: 無依賴純 JS

## 🧪 測試步驟

### 1. 啟動服務

```bash
cd /Users/andycyw/dify/docker
docker-compose up -d wiki-batch-importer
```

### 2. 訪問 Web 界面

```bash
open http://localhost:5050/
```

### 3. 測試功能

**測試儀表板**:
```bash
# 應該顯示統計數據和群組列表
curl http://localhost:5050/api/wiki/smb-status | jq
```

**測試配置管理**:
```bash
# 保存配置
curl -X POST http://localhost:5050/api/smb-configs \
  -H "Content-Type: application/json" \
  -d '{
    "group": "EE",
    "smbPath": "/app/smb/EE",
    "targetPath": "/smb/EE",
    "scanInterval": 300,
    "autoSync": true
  }'

# 獲取配置
curl http://localhost:5050/api/smb-configs | jq
```

**測試批量導入**:
```bash
# 掃描目錄
curl -X POST http://localhost:5050/api/wiki/scan-directory \
  -H "Content-Type: application/json" \
  -d '{"sourcePath": "/app/test_data"}' | jq

# 批量導入
curl -X POST http://localhost:5050/api/wiki/batch-directory-import \
  -H "Content-Type: application/json" \
  -d '{
    "sourcePath": "/app/test_data",
    "targetFolder": "/imported",
    "preserveStructure": "true"
  }' | jq
```
