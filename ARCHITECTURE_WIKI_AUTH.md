## 認證流程圖

```
                    用戶
                     │
                     │ 輸入帳密
                     ▼
        ┌────────────────────────┐
        │  dify-next-frontend    │
        │     /login 頁面         │
        └────────────┬───────────┘
                     │
                     │ POST /api/auth/callback/credentials
                     ▼
        ┌────────────────────────┐
        │     NextAuth.js        │
        │  CredentialsProvider   │
        └────────────┬───────────┘
                     │
                     │ authorize(credentials)
                     ▼
        ┌────────────────────────┐
        │  wiki-auth-adapter.ts  │
        │ verifyUserCredentials()│
        └────────────┬───────────┘
                     │
                     │ Prisma query
                     ▼
        ┌────────────────────────┐
        │   PostgreSQL (users)   │
        │   + userGroups查詢      │
        └────────────┬───────────┘
                     │
                     │ 返回用戶 + 組
                     ▼
        ┌────────────────────────┐
        │  bcrypt.compare()      │
        │    驗證密碼             │
        └────────────┬───────────┘
                     │
                     │ 密碼正確
                     ▼
        ┌────────────────────────┐
        │   getUserRole()        │
        │  判斷角色映射           │
        └────────────┬───────────┘
                     │
                     │ administrators → admin
                     │ 其他 → user
                     ▼
        ┌────────────────────────┐
        │  生成 JWT token        │
        │  payload: {            │
        │    userId, email,      │
        │    role, groups        │
        │  }                     │
        └────────────┬───────────┘
                     │
                     │ 返回 session
                     ▼
        ┌────────────────────────┐
        │  前端保存 session       │
        │  顯示用戶信息           │
        └────────────────────────┘
                     │
                     │ 後續請求攜帶 JWT
                     ▼
                  登入成功
```

## 安全架構

```
┌────────────────────────────────────────────────────────────┐
│                    安全層級                                 │
├────────────────────────────────────────────────────────────┤
│                                                             │
│  Layer 1: 傳輸層安全                                        │
│  ┌───────────────────────────────────────────────┐        │
│  │  HTTPS (生產環境建議)                          │        │
│  │  TLS 1.2+                                      │        │
│  └───────────────────────────────────────────────┘        │
│                                                             │
│  Layer 2: 認證層                                           │
│  ┌───────────────────────────────────────────────┐        │
│  │  JWT Token (7 天有效期)                        │        │
│  │  ├─ HS256 簽名算法                             │        │
│  │  ├─ Secret Key 加密                            │        │
│  │  └─ Payload: userId, email, role, groups      │        │
│  └───────────────────────────────────────────────┘        │
│                                                             │
│  Layer 3: 密碼安全                                         │
│  ┌───────────────────────────────────────────────┐        │
│  │  bcrypt (10 rounds)                            │        │
│  │  ├─ 單向加密                                   │        │
│  │  ├─ Salt 自動生成                              │        │
│  │  └─ 無法逆向解密                               │        │
│  └───────────────────────────────────────────────┘        │
│                                                             │
│  Layer 4: 數據庫安全                                       │
│  ┌───────────────────────────────────────────────┐        │
│  │  Prisma ORM                                    │        │
│  │  ├─ 參數化查詢 (防 SQL 注入)                   │        │
│  │  ├─ 類型安全                                   │        │
│  │  └─ 連接池管理                                 │        │
│  └───────────────────────────────────────────────┘        │
│                                                             │
│  Layer 5: 授權層                                           │
│  ┌───────────────────────────────────────────────┐        │
│  │  基於角色的訪問控制 (RBAC)                     │        │
│  │  ├─ admin: 完整權限                            │        │
│  │  └─ user: 受限權限                             │        │
│  └───────────────────────────────────────────────┘        │
│                                                             │
└────────────────────────────────────────────────────────────┘
```

## 性能優化

```
┌────────────────────────────────────────────────────────────┐
│                  性能優化策略                               │
├────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 數據庫層                                               │
│     ├─ PostgreSQL 索引                                     │
│     │  ├─ users.email (unique)                            │
│     │  ├─ userGroups.userId                               │
│     │  └─ userGroups.groupId                              │
│     │                                                       │
│     ├─ Prisma 查詢優化                                     │
│     │  ├─ select: 只查詢必要欄位                          │
│     │  ├─ include: 一次性載入關聯                         │
│     │  └─ where: 使用索引欄位                             │
│     │                                                       │
│     └─ 連接池                                              │
│        ├─ 最大連接數: 10                                   │
│        └─ 連接複用                                         │
│                                                             │
│  2. 認證層                                                 │
│     ├─ JWT Session                                         │
│     │  ├─ 用戶組緩存在 token 中                           │
│     │  └─ 減少數據庫查詢                                   │
│     │                                                       │
│     └─ Session 持久化                                      │
│        └─ 7 天有效期                                       │
│                                                             │
│  3. 應用層                                                 │
│     ├─ Next.js                                             │
│     │  ├─ SSR: 服務端渲染                                 │
│     │  ├─ 靜態生成: 公開頁面                               │
│     │  └─ API Routes: 後端 API                            │
│     │                                                       │
│     └─ React                                               │
│        ├─ Context: 避免 prop drilling                      │
│        └─ useMemo/useCallback: 減少重新渲染                │
│                                                             │
└────────────────────────────────────────────────────────────┘
```
